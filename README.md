# QA Automation Trainee Task

This project contains solutions for the technical task for a QA Automation trainee position.

## Requirements

* Python 3
* No additional libraries are required

## Project structure

```text
main.py
task1_number.py
task2_name.py
task3_list.py
README.md
```

## How to run

Run the main program from the project folder:

```bash
python main.py
```

After starting the program, select one of the available tasks:

```text
Choose a program
1 - Check number
2 - Check name
3 - Check multiples
4 - Exit
```

### Task 1

If the entered number is greater than 7, the program prints:

```text
Hello
```

### Task 2

If the entered name is `John`, the program prints:

```text
Hello, John
```

Otherwise:

```text
There is no such name
```

### Task 3

The program receives a numeric array and prints the elements that are divisible by 3.

Example:

```text
Input:
1 3 5 6 8 9 12

Output:
3
6
9
12
```

## Bracket sequence

Given sequence:

```text
[((())()(())]]
```

The sequence is not correct because the brackets are not balanced.

Correct version:

```text
[((())()(()))]
```
